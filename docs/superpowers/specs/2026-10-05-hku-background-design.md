# 香港大学校园背景视觉设计

## 目标

为计算器页面增加真实的香港大学校园照片作为环境背景，提升页面空间感和个人识别度，同时保持计算器工具的清晰、克制和可操作性。

## 视觉方案

- 使用一张可公开使用的香港大学校园照片，下载为本地资源，避免依赖外部图片服务。
- 图片仅出现在页面底层伪元素中，不进入计算器和历史面板的内容层。
- 背景图使用约 18-22px 模糊、轻度降饱和和低透明度；浅色主题增加冷白遮罩，深色主题增加石墨蓝遮罩。
- 面板维持不透明表面，保留现有蓝色显示区、按钮和历史分页，不使用大面积渐变或复杂动画。

## 结构与响应式

页面结构不变：桌面端继续使用计算器左、历史右的双栏布局，移动端继续堆叠为单栏。背景层使用 `body::before` 或 `.page::before`，并通过 `pointer-events: none` 保证不拦截交互。

## 可访问性与性能

- 背景图片作为装饰，不承载信息；正文对比度由面板实色保证。
- 为 `prefers-reduced-motion` 保留现有静态表现，不加入持续动画。
- 使用压缩后的本地 WebP/JPEG，控制文件尺寸；在 README 中记录图片来源和许可信息。

## 不在本次范围内

- 不修改计算、历史、分页、搜索、删除、双语或主题切换逻辑。
- 不引入 Tailwind、React 组件库或新的运行时依赖。
- 不制作独立的营销型首页或复杂动态背景。
